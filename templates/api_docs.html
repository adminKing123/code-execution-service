Code Execution Service API

Run Python in an isolated subprocess. Every run is logged in the admin console.

Base URL: http://{{ flask_host }}:{{ flask_port }}
API key: set SERVICE_API_KEY in .env; copy it from Admin → Test run after login.

Authentication

Every request must include your service API key:

  • Authorization: Bearer <SERVICE_API_KEY>
  • X-API-Key: <SERVICE_API_KEY>

List languages

GET /api/languages

Execute code

POST /api/execute · Content-Type: application/json

FieldTypeRequiredDescription
languagestringNoDefault python.
codestringYesSource. Max {{ max_code_kb }} KB (Settings).
streambooleanNoSSE response with live logs.
include_logsbooleanNoAttach stdout/stderr lines in JSON (non-stream).

Timeout: {{ execution_timeout_seconds }} seconds (Settings).

Responses

StatusMeaning
200Success JSON with log_id, optional result.
400Validation error with log_id.
422Execution failed (syntax, runtime, timeout).
401Invalid API key.

SSE events

started → log → complete or error. Events include log_id on started.
