Code Execution Service API

Run Python in an isolated subprocess. Every run is logged in the admin console.

Base URL: http://{{ flask_host }}:{{ flask_port }}
API key: set SERVICE_API_KEY in .env; copy it from Admin → Test run after login.

Authentication

Every request must include your service API key:

  • Authorization: Bearer <SERVICE_API_KEY>
  • X-API-Key: <SERVICE_API_KEY>

List languages

GET /api/languages

Execute code

POST /api/execute · Content-Type: application/json

FieldTypeRequiredDescription
languagestringNoDefault python.
codestringYesSource. Max {{ max_code_kb }} KB (Settings).
stdin_linesstring[]NoLines consumed by each input() call, in order.
include_logsbooleanNoInclude captured print output in JSON logs.
streambooleanNoAlias for include_logs (response is always JSON).

Timeout: {{ execution_timeout_seconds }} seconds (Settings).

Successful run with no main(), or main() returning null, returns ok: true and HTTP 200. Guardrails block risky imports and open/exec/eval.

Responses

StatusMeaning
200Success JSON with log_id, optional result.
400Validation error with log_id.
422Execution failed (syntax, runtime, timeout).
401Invalid API key.

Input via stdin_lines

User code cannot read from a real terminal. Each input() takes the next string from stdin_lines (prompt text is ignored). Multiple calls use multiple entries, in order. If code calls input() more often than lines provided, the run fails at runtime (HTTP 422), not a hang.

{
  "code": "a = input('A? ')\nb = input('B? ')\ndef main():\n    return [a, b]",
  "stdin_lines": ["first", "second"]
}

Example — cURL

curl -X POST "http://{{ flask_host }}:{{ flask_port }}/api/execute" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_SERVICE_API_KEY" \
  -d "{\"language\":\"python\",\"code\":\"def main(): return 1\",\"include_logs\":true}"

Example — main() optional

{
  "code": "print('setup only')"
}
→ 200 {"ok": true, "has_main": false, ...}
